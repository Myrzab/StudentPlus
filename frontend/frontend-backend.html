FRONTEND & BACKEND

Web сайттың екі жағын бірге үйрен.

Frontend — пайдаланушы көретін интерфейс. Backend — сайттың артында жұмыс істейтін серверлік жүйе. Ал осы екі бағытты да меңгерген маман — Full Stack Developer.

Frontend ↓ Backend ↓ Full Stack ↓
fullstack.js 
const frontend = [
    "HTML",
    "CSS",
    "JavaScript"
];

const backend = [
    "Node.js",
    "API",
    "Database"
];

const fullStack =
    frontend + backend;

FRONTEND DEVELOPMENT

Frontend дегеніміз не?

Frontend — веб-сайттың немесе веб-қосымшаның пайдаланушыға көрінетін бөлігі. Пайдаланушы сайтқа кірген кезде көретін барлық интерфейс элементтері Frontend арқылы жасалады.

Оған менюлер, батырмалар, мәтіндер, суреттер, карточкалар, формалар, анимациялар, навигация және басқа да визуалды элементтер кіреді.

FRONTEND DEVELOPER

Frontend Developer не істейді?

Frontend Developer дизайнер дайындаған интерфейсті нақты жұмыс істейтін веб-сайтқа айналдырады. Оның негізгі міндеті — пайдаланушыға түсінікті, ыңғайлы және жылдам интерфейс жасау.

01 UI Пайдаланушы интерфейсін жасау.
02 Responsive Телефон, планшет және компьютерге бейімдеу.
03 JavaScript Сайтқа интерактивтілік қосу.
04 API Серверден мәлімет алу.
05 UX Пайдаланушыға ыңғайлы тәжірибе жасау.
06 Animation Анимациялар мен визуалды эффектілер жасау.

BACKEND DEVELOPMENT

Backend дегеніміз не?

Backend — веб-сайттың пайдаланушыға тікелей көрінбейтін серверлік бөлігі. Ол сайттың ішкі логикасын орындайды және Frontend-пен мәлімет алмасады.

Мысалы, пайдаланушы жүйеге кірген кезде Frontend логин мен парольді Backend-ке жібереді. Backend бұл ақпаратты тексеріп, Database-пен жұмыс істейді және нәтижені қайтарады.

BACKEND DEVELOPER

Backend Developer не істейді?

Backend Developer қосымшаның серверлік бөлігін жасайды. Ол серверді, API-ді, Database-пен байланысты және қолданушының сервермен жұмыс істеу логикасын ұйымдастырады.

01 Server Серверлік қосымшалар жасау.
02 API Frontend пен Backend байланыстыру.
03 Database Мәліметтерді сақтау және алу.
04 Authorization Тіркелу және кіру жүйесін жасау.
05 Security Серверлік жүйені қорғау.
06 Logic Қосымшаның негізгі логикасын жазу.

FULL STACK DEVELOPMENT

Frontend + Backend
= Full Stack

Full Stack Developer — веб-қосымшаның Frontend және Backend бөліктерін қатар жасай алатын маман. Ол интерфейстен бастап серверге және Database-ке дейінгі процестерді түсінеді.

01

Frontend

HTML, CSS, JavaScript және басқа Frontend технологиялары арқылы пайдаланушы интерфейсін жасау.

02

Backend

Node.js және басқа серверлік технологиялар арқылы қосымшаның ішкі жүйесін жасау.

03

API

Frontend пен Backend арасында ақпарат алмасуды ұйымдастыру.

04

Database

Қосымшадағы қажетті мәліметтерді сақтау және басқару.

05

Authentication

Пайдаланушыларды тіркеу және жүйеге кіру мүмкіндігін ұйымдастыру.

06

Complete Project

Frontend, Backend және Database біріктіріп толыққанды веб-жоба жасау.

WHY FULL STACK?

Неліктен Frontend және Backend екеуін де үйрену керек?

01

Жобаны толық түсіну

Қосымшаның пайдаланушы көретін бөлігін де, ішкі серверлік жүйесін де түсінуге мүмкіндік береді.

02

Өз жобаңызды жасау

Идеядан бастап дайын веб-қосымшаға дейін жобаны өз бетіңізше жасауға мүмкіндік береді.

03

IT бағытын кеңейту

Frontend, Backend, API және Database туралы біртұтас түсінік қалыптасады.
